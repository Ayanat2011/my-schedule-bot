# Telegram-бот «Мой распорядок» (Детский помощник) 🗓️✨

Полнофункциональный, современный Telegram-бот личный помощник для родителей и детей. Бот помогает семьям легко организовывать расписание школьных уроков, дополнительных секций, кружков, тренировок и репетиторов, а также заблаговременно присылает умные дружелюбные напоминания в Telegram.

---

## 🌟 Ключевые возможности

### 1. 👧👦 Профили детей и семьи
- Регистрация родителя в 1 клик через Telegram.
- Ведение нескольких детей в одной семье (любое количество профилей).
- Для каждого ребёнка указывается имя, возраст и персональный эмодзи-значок.
- **Интеграция с аккаунтом ребёнка:** возможность привязать Telegram ID ребёнка, чтобы он получал личные бодрые напоминания и план на день!

### 2. 📚 Управление расписанием
- Удобное добавление занятий любого типа:
  - 📚 Школьные уроки
  - 🧑‍🏫 Репетиторы
  - 🇬🇧 Английский и иностранные языки
  - 🎵 Музыкальная школа и вокал
  - 💃 Танцы и балет
  - ⚽ Футбол и игровые виды спорта
  - 🏊 Плавание
  - 🥋 Спортивные секции и единоборства
  - 🎨 Творческие кружки и робототехника
  - 📌 Любые другие занятия
- Поддержка:
  - **Регулярных занятий** с выбором любых дней недели (например: Пн, Ср, Пт).
  - **Разовых мероприятий** с фиксацией точной даты.
- Указание времени начала и окончания.
- Привязка места проведения (адрес, кабинет, этаж) из справочника сохранённых локаций.
- Преподаватель / тренер (имя и телефон).
- **Чек-лист необходимых вещей:** бот напоминает взять форму, сменную обувь, воду, учебники или музыкальный инструмент 🎒💧
- Быстрое редактирование, отмена занятия на сегодня или удаление.

### 3. 🔔 Система умных напоминаний
Главная гордость бота — гибкая многоуровневая система автоматических уведомлений:
- **За 1 день** до занятия (накануне вечером или за 24 часа).
- **За 2 часа** до начала.
- **За 30 минут** до начала.
- **За 10 минут** (когда уже пора выходить или заходить в класс).
- Индивидуальная настройка интервалов для каждого занятия (можно отключить ненужные интервалы).
- Раздельная настройка получателей: уведомлять только родителя, только ребёнка или обоих одновременно.
- **Интерактивные кнопки прямо в сообщении-напоминании:**
  - `✅ Занятие посещено` — фиксация выполнения.
  - `❌ Отменить сегодня` — оперативная отмена занятия на текущий день.
  - `ℹ️ Подробнее` — карточка занятия.

### 4. ☀️ Ежедневное утреннее расписание
- Каждое утро (в настраиваемое время, по умолчанию 08:00) бот отправляет структурированный план на день с добрыми мотивирующими пожеланиями.
- Ребёнок получает личный позитивный заряд бодрости на весь день!

### 5. 🛡️ Надёжность и интеллектуальные функции
- **Учёт часовых поясов:** поддержка любых поясов (Москва, Екатеринбург, Алматы, Владивосток и др.).
- **Тихие часы (Quiet Hours):** бот не будет беспокоить ночью (например, с 22:00 до 07:00).
- **Защита от дублирования:** журнал `notification_logs` гарантирует, что ни одно напоминание не придёт дважды.
- **Устойчивость к перезапускам:** бот автоматически восстанавливает расписание и рассчитывает ближайшие события из базы данных.

### 6. 📊 Панель администратора (`/admin`, `/stats`)
- Счётчик зарегистрированных родителей и профилей детей.
- Статистика активных занятий и слотов расписания.
- Счётчик отправленных напоминаний с разбивкой по типам (1 день, 2 часа, 30 минут, 10 минут, утренний дайджест).
- Мониторинг ошибок доставки.

## 🛠️ Стек технологий

- **Язык программирования:** Python 3.12+
- **Telegram Bot Framework:** [aiogram 3.x](https://docs.aiogram.dev/) (современный асинхронный фреймворк с FSM и роутерами)
- **База данных:** PostgreSQL 16 (с поддержкой SQLite для локальных тестов)
- **ORM:** [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (AsyncEngine, Mapped, asyncpg, aiosqlite)
- **Миграции:** [Alembic](https://alembic.sqlalchemy.org/)
- **Конфигурация:** [Pydantic Settings](https://docs.pydantic.dev/) + `.env`
- **Контейнеризация:** Docker & Docker Compose
- **Тестирование:** Pytest + Pytest-Asyncio

## 🚀 Быстрый старт

### Шаг 1. Получение токена Telegram-бота
1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Укажите читаемое имя бота (например: `Мой распорядок — Помощник`).
4. Укажите юзернейм бота, заканчивающийся на `bot` (например: `MyKidsScheduleBot`).
5. Скопируйте полученный токен (вида `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ_1234567`).

### Шаг 2. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
Откройте файл `.env` в текстовом редакторе и укажите ваш `BOT_TOKEN` и ваш числовой ID в `ADMIN_IDS`:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
DEFAULT_TIMEZONE=Europe/Moscow
```

## 🐳 Запуск через Docker & Docker Compose (Рекомендуется)

Запуск всей инфраструктуры (PostgreSQL 16 + Бот с автоматическим применением миграций) выполняется одной командой:

```bash
docker compose up -d --build
```

Просмотр логов:
```bash
docker compose logs -f bot
```

Остановка сервисов:
```bash
docker compose down
```

## 💻 Локальный запуск (без Docker)

### 1. Создание виртуального окружения и установка зависимостей
```bash
python -m venv venv
# Активация:
# Windows (PowerShell):
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Выбор базы данных
- **Вариант А (PostgreSQL):** Убедитесь, что PostgreSQL запущен, и укажите `DATABASE_URL` в `.env`:
  ```env
  DATABASE_URL=postgresql+asyncpg://schedule_user:schedule_password@localhost:5432/schedule_bot_db
  ```
- **Вариант Б (SQLite для быстрой разработки):** Раскомментируйте в `.env`:
  ```env
  DATABASE_URL=sqlite+aiosqlite:///./schedule_bot.db
  ```

### 3. Применение миграций базы данных
```bash
alembic upgrade head
```

### 4. Заполнение демонстрационными данными (опционально)
Чтобы протестировать бота с готовым расписанием (профили Алисы и Максима, школа, плавание, английский, футбол):
```bash
python seed_data.py
```

### 5. Запуск бота
```bash
python -m bot.main
```

## ☁️ Развёртывание на Render.com (Background Worker 24/7)

Так как бот работает в режиме **Long Polling**, на платформе Render он развёртывается как **Background Worker** (фоновый процесс без создания веб-сервера и без открытых HTTP-портов).

### Шаг 1. Публикация репозитория на GitHub (без секретов)
Файл `.gitignore` уже настроен и защищает ваши файлы `.env` и локальные базы данных `*.db` от попадания в Git.

1. Создайте репозиторий на [GitHub](https://github.com) (например, `kids-schedule-bot`).
2. В терминале проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Render Background Worker"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/kids-schedule-bot.git
   git push -u origin main
   ```

### Шаг 2. Развёртывание на Render

#### Вариант А: Быстрое развёртывание через Blueprint (`render.yaml`)
В репозитории уже подготовлен файл `render.yaml`:
1. В панели [Render.com](https://render.com) перейдите в **Blueprints** → **New Blueprint Instance**.
2. Выберите ваш репозиторий GitHub.
3. Render автоматически создаст:
   - Базу данных **PostgreSQL** (`schedule-bot-db`).
   - Фоновый процесс **Background Worker** (`kids-schedule-bot`).
4. При запросе переменной `TELEGRAM_BOT_TOKEN` введите токен вашего бота.
5. Нажмите **Apply**.

#### Вариант Б: Ручное создание сервиса
1. Создайте базу данных: **New +** → **PostgreSQL** (имя `schedule-db`, регион `Frankfurt`, план `Free`).
2. Скопируйте **Internal Database URL** созданной БД.
3. Создайте воркер: **New +** → **Background Worker**:
   - **Name:** `kids-schedule-bot`
   - **Region:** `Frankfurt`
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -m bot.main`
4. В секции **Environment Variables** добавьте:
   - `TELEGRAM_BOT_TOKEN` = `ваш_токен_бота`
   - `DATABASE_URL` = `(вставьте скопированный Internal Database URL)`
   - `DEFAULT_TIMEZONE` = `Europe/Moscow`
5. Нажмите **Create Background Worker**.

Бот автоматически инициализирует таблицы базы данных, запустит фоновый планировщик умных напоминаний и перейдёт в режим приёма сообщений!

## 📱 Меню и команды бота

### Главное меню (Reply Keyboard):
- `📅 Моё расписание` — расписание на сегодня, завтра, всю неделю или фильтрация по ребёнку.
- `➕ Добавить занятие` — пошаговый мастер добавления секции, урока или разового события.
- `👧 Мои дети` — список детей, добавление нового профиля, привязка Telegram ID ребёнка.
- `📝 Редактировать занятия` — управление занятиями, приостановка, отмена на сегодня, удаление.
- `🔔 Настройки напоминаний` — детальная настройка интервалов (1 день, 2ч, 30м, 10м).
- `📍 Места занятий` — справочник школ, студий и бассейнов с адресами.
- `⚙️ Настройки` — выбор часового пояса, тихие часы, время утреннего дайджеста.
- `❓ Помощь` — подробное руководство и справка.
